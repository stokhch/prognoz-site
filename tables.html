Таблицы и журнал

Журнал наблюдений Солнца на РАТАН-600, таблица источников по дням (как «Database tables» старого сайта) и файлы для скачивания. Всё, что показано, можно забрать в CSV или в JSON.

Источники по дням

Локальные источники на сканах дня, отождествлённые с областями NOAA: потоки на 2, 3 и 10 см, поправка на диаграмму k и признак критерия. Для отдельных сканов дня — панель «DB sources» на странице анализа.

Файлы и API

Сайт статический: всё, что он показывает, лежит в открытых JSON-файлах, и их можно читать программой. Форматы описаны в README репозитория сайта.

ФайлЧто в нём
data/forecast.jsonпрогноз на сегодня: итог, таблица Танаки–Эноме, последний скан
feed.xmlRSS-лента прогноза: одна запись в день; подписка в любом читателе RSS
data/history/index.jsonгоды архива
data/history/ГГГГ.jsonпрогноз каждого дня года, таблица источников и вспышки через 12–84 ч
data/indices/ГГГГ.jsonполный поток Солнца за день: РАТАН-600, NoRP (1–17 ГГц), F10.7
data/journal/ГГГГ.jsonжурнал наблюдений: режим, число сканов, азимуты, время
data/observations.jsonсканы, выложенные на сайт, со ссылками на страницу анализа
data/sources/ГГГГ-ММ-ДД.jsonисточники каждого скана дня из базы (V_RAT_AR_NOAA)
